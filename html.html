Temas básicos de HTML

¿Qué es HTML?

HTML significa HyperText Markup Language (Lenguaje de Marcado de Hipertexto). Se utiliza para crear la estructura de las páginas web.

Estructura básica de HTML

Un documento HTML contiene etiquetas que indican cómo se organiza el contenido de una página web.

  • <!DOCTYPE html>: indica que se utiliza HTML5.
  • <html>: contiene todo el documento.
  • <head>: contiene información de la página.
  • <title>: establece el título de la pestaña.
  • <body>: contiene el contenido visible.
