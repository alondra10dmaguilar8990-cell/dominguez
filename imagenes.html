Imágenes en HTML

¿Cómo insertar una imagen?

La etiqueta <img> permite mostrar imágenes dentro de una página web. No necesita etiqueta de cierre.

Atributos principales

  • src: indica la dirección o ubicación de la imagen.
  • alt: proporciona una descripción de la imagen.
  • width: establece el ancho.
  • height: establece la altura.

Ejemplo de código

Este es un ejemplo de cómo insertar una imagen:

<img src="imagenes/flor.svg"
     alt="Dibujo de una flor"
     width="300">

Ejemplo visual

Esta imagen es un dibujo de una flor creado con SVG:

¿Por qué utilizar el atributo alt?

El atributo alt describe la imagen cuando no se puede cargar y ayuda a las personas que utilizan lectores de pantalla.

Conclusión

Las imágenes hacen que las páginas web sean más atractivas y permiten comunicar información de forma visual.
