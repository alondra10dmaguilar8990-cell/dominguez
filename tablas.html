Creación de tablas en HTML

¿Qué es una tabla en HTML?

Una tabla permite organizar información en filas y columnas. Se crea utilizando las etiquetas table, tr, th y td.

Etiquetas principales

  • <table>: crea la tabla.
  • <tr>: crea una fila.
  • <th>: crea una celda de encabezado.
  • <td>: crea una celda con datos.
  • <caption>: agrega un título a la tabla.

¿Cómo funciona?

Cada etiqueta tr representa una fila. Las etiquetas th muestran los encabezados, mientras que td contiene los datos de cada celda.

Conclusión

Las tablas son útiles para mostrar información organizada, como listas de alumnos, horarios y calificaciones.
